# nomad-momentum

> 노마드 코더 **"바닐라 JS로 크롬 앱 만들기"** 강의 기반으로 제작한 모멘텀 클론코딩 입니다.  
> 기본 구현에 더해 **CSS** 및 자주 방문하는 웹사이트를 저장할 수 있는 **바로가기 기능**을 추가로 구현했습니다.

---

## 주요 기능

- **실시간 시계 & 인사말:** 사용자 이름 저장 및 시계 표시
- **투두리스트(To Do List):** 할 일 추가/삭제 및 완료 표시, LocalStorage 상태 유지
- **사이트 바로가기:** 링크 추가 및 삭제 기능
- **날씨 & 위치 정보:** Geolocation API 및 OpenWeatherMap API 활용
- **랜덤 배경화면 & 명언:** 페이지 새로고침 시 랜덤 렌더링

## 회고

웹 개발을 처음 접하며 지식이 부족한 상태였지만, 우선 **프로젝트를 완성하는 경험**을 목표 삼아 AI 도구를 보조적으로 활용하여 개발을 시작했습니다.

하지만 프로젝트가 커질수록 AI가 생성해 준 코드에 대해 제대로 된 이해가 부족해 손대거나 리팩토링하기가 점점 힘들어지는 한계를 겪었습니다.

비록 모든 코드를 온전히 혼자 작성한 것은 아니지만, 웹 앱을 만들어가는 과정 자체가 매우 흥미로웠습니다.

이번 경험을 통해 단순 기능 구현을 넘어 앞으로는 **내용을 이해하고 스스로 나만의 코드를 짜고 싶다**는 생각을 하게 되었습니다.
